我的世界服务器管理软件

项目名称为 Minecraft Server Manager，这是一款基于 PyQt6 框架开发的轻量级 Minecraft Fabric 服务器部署与可视化管理工具。该项目旨在为玩家和服务器管理员提供直观、高效的本地服务器搭建、配置及运维体验，摆脱传统命令行繁琐的操作过程。
在服务器部署方面，该软件支持一键式获取并安装官方 Fabric 游戏版本。系统会自动拉取 Fabric 官方元数据，下载所需的构建文件，并自动生成相关的启动脚本与配置文件。整个构建流程采用异步多线程处理，配合底部状态栏的实时进度展示，确保软件界面在下载和构建过程中始终保持流畅不卡顿。
在实例管理与控制方面，系统提供了丰富的自定义选项。用户可以方便地启动或停止服务器，并通过集成的实时控制台窗口发送指令与查看运行日志。控制台内置了强壮的日志解码逻辑，能有效防止 Windows 平台下因字符编码冲突导致的程序崩溃。此外，用户还可以直观地调整服务器的最大分配内存、视距、仿真距离以及玩法规则，如游戏模式、困难度、PVP 开关和网络端口等。
在数据安全与维护方面，软件内置了自动化世界备份机制。用户不仅可以随时手动触发地图备份，还能设置定时自动备份任务。备份模块会自动将游戏世界文件夹打包压缩为带有时间戳的压缩包，并具备旧备份自动清理功能，有效节省磁盘存储空间，保障游戏存档的安全无忧。
在界面设计与交互体验方面，软件采用了现代暗黑风格的视觉样式，结合了精美的深色卡片布局。为了提升操作的质感，项目加入了丰富的平滑过渡动画，包括卡片入场的弹跳效果、按钮点击的微下压反馈以及部署成功的淡入提示。整体代码采用模块化结构设计，将多线程逻辑、样式配置、弹窗交互与主窗口解耦，保证了良好的代码可维护性与扩展性。
在部署与安装环节，项目解决了长时间网络下载与服务端构建导致界面卡死的问题。系统设计了独立的安装线程，通过继承 PyQt6 的 QThread 实现了任务的后台化处理。在安装过程中，线程实时向主界面发送进度信号，主界面根据信号动态更新状态栏的进度条和提示文本。通过整合 HTTP 请求库获取 Fabric 官方元数据与子进程调用 Java 命令行，实现了从环境准备、文件下载到服务生成的全自动一键部署。
在控制台日志与进程管理方面，项目重点解决了 Windows 操作系统下常见的字符编码冲突问题。在运行 Java 版服务端时，控制台输出经常夹杂 GBK 与 UTF8 两种编码，直接解码极易引发程序崩溃。为此，进程管理器采用了二进制流逐行读取机制，并构建了具备退避恢复功能的解码链。系统优先尝试使用 UTF8 解码，若发生解码异常则自动降级采用 GBK 进行容错替换处理，保证了控制台日志输出的稳定性与完整性。
在图形界面交互与动效呈现上，项目解决了原生窗口动画闪烁以及连续点击导致控件形变的问题。为了实现流畅的动效，项目封装了自定义的弹跳与渐变动画组件。对于顶级对话框窗口，系统会自动识别并采用透明度渐变取代几何尺寸变换，彻底消除了操作系统窗口边框在重绘时的闪烁现象。对于按钮点击反馈，系统通过锁定原始几何坐标与绑定运行状态标志，防止用户快速连续点击时按钮尺寸不断变小的缺陷。
在服务运维与资源控制方面，项目提供了针对性的误操作防护与自动化管理方案。为了防止用户在滑动主界面时误触滑动条改变服务器视距或内存参数，项目自定义扩展了滑动条控件，屏蔽了鼠标滚轮事件，使其专注于滚动事件的传递。在备份管理上，内置的备份线程实现了世界地图文件的异步压缩，并引入了旧备份自动清理算法，严格限制存储数量以防磁盘溢出。在多实例控制上，系统加入了运行状态强校验，确保同一时间内仅允许一个服务器实例运行，有效避免了端口冲突与系统资源过度消耗。
